Logbook — Помощь

Приложение для ведения формуляров авиационной техники.

1. Основные понятия

  • Профиль — единица техники (например, борт №92).
  • День — одна дата с записями полётов или СНК.
  • Формуляр — таблица с наработкой (Часть 1, ВР-80, Та-14, ВК-2500-01/02, Ресурсы).

2. Ежедневная работа

  1. Выберите профиль и дату слева.
  2. Введите экипаж и запуски (ВСУ, Земля, Воздух).
  3. Нажмите «Закончить день» — данные попадут в формуляры.
Режим СНК: переключитесь кнопкой СНК, заполните значения A–K, затем «Закончить день».

3. Сохранение

  • Ctrl+S — сохранить всё вручную.
  • Автосохранение — каждые 5 минут (включено по умолчанию).
  • Ctrl+Z — отменить последнее действие.

4. Настройки

Кнопка ⚙ справа сверху. Разделы:

  • Интерфейс — тема, шрифт, размер текста.
  • Действия — профили, резервные копии, печать.
  • Дополнительно — автозапуск, трей, путь к данным.

5. Печать

Настройки → Действия → «Распечатать». Выберите страницы и принтер, либо «Microsoft Print to PDF» для сохранения в PDF.

6. Горячие клавиши

  • Ctrl+S — сохранить
  • Ctrl+Z — отменить
  • Ctrl+колесо мыши — масштаб (0.3–2.0)

7. Итоги за месяц

В каждом формуляре автоматически создаётся строка «Итого за месяц»:

  • Если есть предыдущий месяц с записями — итог считается как разница крайних значений (для накопительных колонок) или как сумма (для дневных).
  • Если предыдущего месяца нет — итог считается сложением строк месяца, а строка выделяется красной рамкой. При наведении появляется подсказка «Необходим ручной пересчет».
  • Значение 0 в итогах отображается как — (длинное тире).
Формуляры ВК-2500-01/02 не считают итог при отсутствии предыдущего месяца — строка остаётся пустой, но выделяется красной рамкой для ручного пересчёта.

Обмен с Android и обновления

Пять формуляров, полёты, ресурсы агрегатов и масел, история замен, печать и PDF. Работа без интернета и резервные копии. Обмен с Android в обе стороны: через интернет или по Wi-Fi с QR-кодом. Перед заменой книги сохраняется копия; при конфликте выбирается версия книги целиком.

Проверка обновлений: Настройки → О программе → Проверить обновление. Для проверки нужен интернет. Загрузка открывается в браузере; если ссылка ещё не размещена, кнопка скачивания скрыта.
