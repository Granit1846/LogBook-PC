Logbook — Help

Application for maintaining aircraft logbooks.

1. Key concepts

  • Profile — a unit of equipment (e.g., aircraft #92).
  • Day — one date with flight or HC records.
  • Logbook — table with operating hours (Part 1, VR-80, Ta-14, VK-2500-01/02, Resources).

2. Daily workflow

  1. Select a profile and date on the left.
  2. Enter the crew and starts (APU, Ground, Air).
  3. Click "End day" — data will go to the logbooks.
HC mode: switch with the HC button, fill in values A–K, then "End day".

3. Saving

  • Ctrl+S — save everything manually.
  • Auto-save — every 5 minutes (enabled by default).
  • Ctrl+Z — undo the last action.

4. Settings

⚙ button in the top right corner. Sections:

  • Interface — theme, font, text size.
  • Actions — profiles, backups, printing.
  • Advanced — auto-start, tray, data path.

5. Printing

Settings → Actions → "Print". Select pages and printer, or "Microsoft Print to PDF" to save as PDF.

6. Hotkeys

  • Ctrl+S — save
  • Ctrl+Z — undo
  • Ctrl+mouse wheel — zoom (0.3–2.0)

7. Monthly totals

Each logbook automatically creates a "Monthly total" row:

  • If a previous month with records exists — the total is calculated as the difference between the last values (for cumulative columns) or as a sum (for daily columns).
  • If there is no previous month — the total is calculated by summing the month's rows, and the row is highlighted with a red border. Hovering over it shows the tooltip "Manual recalculation required".
  • A value of 0 in totals is displayed as — (em dash).
VK-2500-01/02 logbooks do not calculate totals when there is no previous month — the row remains empty but is highlighted with a red border for manual recalculation.

Android exchange and updates

Five logbooks, flights, component and oil resources, replacement history, printing and PDF. Offline work and backups. Two-way exchange with Android over the internet or Wi-Fi using a QR code. A backup is made before replacing the book; conflicts are resolved by choosing a complete book version.

Check for updates: Settings → About → Check for updates. An internet connection is required. Downloads open in your browser; the download button is hidden until the file link is published.
